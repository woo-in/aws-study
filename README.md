## 📌 이 책을 읽는 이유

AWS를 간단하게 사용해 본 적은 있지만, **잘 모르고 썼습니다.**
콘솔을 열 때마다 VPC, 서브넷, 보안 그룹, IAM, AMI처럼 **모르는 용어들이 계속 나왔고**, 설정값의 의미를 모른 채 넘어가는 일이 반복됐습니다.

- 따라 하면 동작은 했지만, 각 설정이 무엇을 뜻하고 왜 필요한지 설명할 수 없었습니다.
- 용어를 모르니 문서를 읽어도 막히고, 같은 부분에서 매번 다시 헤맸습니다.

그래서 **한 번은 개념을 제대로 익혀 두자**는 생각으로, 그림으로 AWS의 구조를 풀어 주는 이 책을 읽습니다.
